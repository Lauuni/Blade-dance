허수아비는 쓰러지지 않습니다. 마음껏 콤보를 연습하세요.

PC 키보드

  • ←→ 이동
  • →→ 빠르게 두 번 = 달리기 (달리며 X = 질주베기)
  • X 공격 (연타·꾹 누르기로 4연격)
  • C / ↑ / Space 점프 · 공중 2단 점프
  • Z / Shift 대시 (대시 중 공격 = 돌진 찌르기)
  • ASD 기술 1·2·3
  • Tab 기술 교체 · R 허수아비 리셋 · M 소리
  • T 테스트 설정 · L 콤보 노트 · R 리셋 + 쿨타임 초기화
  • 키는 테스트 설정 → 키 설정에서 바꿀 수 있어요

모바일 터치

  • 왼쪽 화면 드래그 → 이동 (위로 튕기면 점프)
  • 같은 방향으로 빠르게 두 번 밀기 → 달리기
  • 큰 빨간 버튼 → 공격 (꾹 누르면 자동 연격)
  • 주변 3개 버튼 → 장착한 기술
  • 점프 · 대시 버튼
콤보 팁 — 기본 공격이 맞으면 언제든 기술·점프·대시로 캔슬됩니다.
콤보 규칙 — 콤보는 시간이 아니라 적 상태로 끝납니다. 적이 다운되거나, 서서 맞다가 경직이 풀리면 끝. 바운드 속성 공격에 맞고 떨어지면 튕겨 올라 콤보가 이어집니다. 보정 게이지는 평타↔스킬로 공격 종류를 바꾼 첫 타에 회복돼요.
예) 공격×3 → 승룡참으로 띄우기 → 점프 → 공중 공격×3(내려찍기) → 튕겨 오를 때 낙뢰추 → 일섬으로 마무리
